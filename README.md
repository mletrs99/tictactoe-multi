Description

This project is a multiplayer Tic Tac Toe game using Node.js, Express, and WebSockets. 
Two players can play against each other, while additional users can join as spectators.

The game was updated for deployment on Render by allowing the server to use the port assigned through an environment 
variable and by automatically selecting the appropriate WebSocket protocol (WS or WSS).
